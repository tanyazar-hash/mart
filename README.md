# КФХ Мартынова — главная страница (прототип)

Сайт для хозяйства в селе Светлое Завьяловского района Алтайского края. React + Vite, адаптивная главная страница.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Пока прототип

- Фотографии внешние и демонстрационные; заменить на реальные фотографии хозяйства.
- Падение семян справа реализовано на Canvas как облегчённая временная анимация. После получения моделей wheat.glb и sunflower.glb можно заменить на Three.js с instancing.
- Название юридического лица, характеристики продукции, телефон и реквизиты требуют уточнения.
- Ссылки в навигации ведут на секции главной страницы; остальные страницы добавим позже.
- Репозиторий FORM / FACTOR (port1) не изменяется.
